# 車機下載中心 0.3.0 測試版

Android 6 以上，套件 app.car.downloadcenter.test，target SDK 35。
更新時保留已安裝 App 與原資料。從同一簽章的 APK 覆蓋安裝後開啟下載中心。

以 GitHub main 分支 download-center/catalog.json 管理 Shield、啟動器與 CarSync 清單；新增版本不必重建 App。APK 下載後核對 SHA-256、套件、版本、簽章及防降版，再由 Android 系統讓使用者確認安裝。離線顯示上次成功清單，首次離線使用內建清單。

下載期間保持畫面開啟；取消安裝可使用保留的最新 APK 重試。正式發布檔會與上一個已發布 APK 核對憑證；CI 臨時 debug 簽章不同，CI 產物不可直接視為可覆蓋發布版。

## 建置與驗證

Java 17、Gradle 8.11.1、Android SDK 35：在 download-center 執行 gradle :app:assembleDebug :app:lintDebug。
CI 同時執行七項清單合約測試與 ApkCacheTest 檔案清理策略測試。設備畫面及安裝流程仍需實機驗證。
工作流程只建置，不自動發布。

## 0.3.0 本機安裝檔自動清理

每次開啟／檢查更新及新版下載完成後，整理此下載中心私有 verified 目錄。以 APK 套件名稱分組，各保留版本代碼最高的一份（同代碼取最近下載者）。先驗證新 APK 的 SHA-256、套件、版本、簽章與防降版，再存入並清理舊版；下載／驗證失敗不會移除原檔。清單出現新版不會單憑清單刪除尚可使用的舊安裝檔。升級後首次開啟也會整理 0.2.0 累積的 hash 檔。

清理前重新核對檔名雜湊與 APK metadata；損壞的自有安裝檔移除。失敗下載的暫存檔在 finally 立即移除；因中斷殘留且超過一小時的 download-*.part 在整理時移除，避免影響剛開始的下載。清理 I/O 失敗顯示提示並在下次重試。只處理自有目錄內固定命名檔案，不遞迴、不碰已安裝 App、其他資料或外部 Download 資料夾。安裝取消時保留最新一份供重試。


## 固定簽章發布（0.3.0 起）

0.2.0 的已發布測試版與 Review 版使用不同一次性簽章；升級 0.3.0 必須先下載新版，再只移除舊下載中心後安裝。移除下載中心會清空其私有清單及 APK 快取，不移除其他 App。
